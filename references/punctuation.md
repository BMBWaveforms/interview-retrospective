# 问题与回答的标点整理（强制）

“原话不润色”指保留用词和内容，不等于交付无标点的转写。面试官主问、追问、候选人反问和全部回答都必须按语义补齐正常标点；原始识别稿仍作为本地底稿保留。

- 按语义停顿使用逗号，完整陈述使用句号，实际疑问使用问号；并列内容、解释和引用按需用顿号、分号、冒号或引号。指令式提问不必硬加问号。不能只在整段末尾补一个句号，也不能把每个ASR片段机械当成一句话。
- 只补充或调整阅读标点，不增删、替换或重排任何字词；保留重复、语气词、自我更正、口语语病和未说完的句子。不能趁补标点改错别字、推测产品名、补主语、合并重复或润色成书面语。不能可靠判断的断句采用保守停顿，不改变肯定、否定或疑问的含义。
- 中文语境优先用中文全角标点。小数、版本号、日期、时间戳、单位、英文大小写、技术标识、URL、代码和已有不确定标记完整保留；这些结构中的点号、连字符、斜杠、冒号等不是可随意替换的阅读标点。
- 保留原有空格、换行、发言顺序、说话人和问答对应关系。为显示宽度使用代码块原生自动换行，不插入硬换行。原本未作答的空白保持为空，不添加句号或占位文字。
- 本地同时保留原始稿与标点整理稿。逐段复核断句后运行 `python3 scripts/check_punctuation.py < punctuation-pairs.json`。输入为 `[{"id":"Q01","before":"这个项目你负责什么","after":"这个项目，你负责什么？"}]`。校验不允许以“去掉所有标点后相同”替代对数字、技术结构和不确定标记的检查；脚本通过也不能代替语义断句复核。
- 写入后回读全部问题和回答，与标点整理稿逐段相等，并重新验证仅标点变化。已有文档局部更新问答原生块，保留题号、时间、原视频、评分、诊断和用户已填写的黄色块；回读实际自动换行状态。原始稿与校验清单只留本地，不追加正文附录。
