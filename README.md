# 面试复盘 Skill

把一轮面试整理成可回到原话核对的复盘文档。支持音频、视频和逐字文本。视频原件随本轮归档。每次运行都会询问你想用什么文档格式、放到哪里，也需要你提供可读取的岗位 JD 来源。

## 安装

下载或克隆本仓库，将包含 SKILL.md 的目录命名为 interview-retrospective，放入 Codex 的用户 Skills 目录（通常是 ~/.codex/skills/）。打开新对话并输入：

> 用 $interview-retrospective 复盘附件里的技术二面。公司是……，岗位是……，JD 在……。

只想试用时可加“先给预览”。Skill 会询问这次的格式和位置。你可以选一个飞书知识库节点，也可以选一个本地目录来保存带视频的可编辑网页。请在使用时提供自己的地址和权限。

## 文档内容

公司文档版头放实际 JD 全文和链接；每轮包含面试官问题／追问、候选人逐字回答、本轮评分报告和完整逐字稿。🔴 指关键失误，🟡 指核心答得不错且有具体增强机会。标记题下保留诊断和黄色空块供你亲自改写。无须改的题只列问答。

## 环境

文本输入可直接整理。本地媒体转写脚本需 Python、faster-whisper、ffmpeg 及已缓存的兼容模型；首次部署可自行安装这些依赖并准备模型。不会自动下载模型或上传录音。机器结果需核听，身份或原话不清时会提示确认。只有选飞书时才需要已配置用户身份并有相应权限的 lark-cli。其他格式由运行 Skill 的助手在目标环境中适配，无法支持的样式会先与你确认。

入口在 [SKILL.md](SKILL.md)，飞书模板在 [assets/document.xml](assets/document.xml)。评分脚本只使用 Python 标准库。许可见 [MIT License](LICENSE)；第三方软件与模型遵循各自许可。
